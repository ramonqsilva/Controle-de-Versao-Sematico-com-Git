# 📌 Controle de Versão Semântico  

## 🎓 Atividade Avaliativa – Faculdade Belas Artes  

Este repositório foi desenvolvido como atividade avaliativa da **Faculdade Belas Artes**, com o objetivo de exercitar o uso do **Versionamento Semântico (Semantic Versioning)** utilizando **tags no GitHub**.  

---

## 🎯 Objetivo da Atividade  

- Praticar o controle de versões de um projeto utilizando o padrão **SemVer 2.0.0**  
- Aplicar corretamente a criação e evolução de versões através de **tags semânticas no GitHub**  
- Compreender como organizar versões de software de forma padronizada e profissional  

---

## 🧩 Sobre o Projeto  

O projeto consiste em uma aplicação simples para **cálculo de IMC (Índice de Massa Corporal)**.  

### Funcionalidades:
- Inserir peso e altura  
- Calcular o IMC automaticamente  
- Exibir a classificação do resultado (baixo peso, normal, sobrepeso, etc.)  

Este projeto serve como base prática para aplicar o **versionamento semântico** durante sua evolução.  

---

## 🏷️ Uso das Tags  

As versões do projeto são controladas através de **tags no GitHub**, simulando ciclos reais de desenvolvimento de software.  

- Cada nova funcionalidade, melhoria ou correção gera uma nova versão conforme as regras do **SemVer**.  

---

## 🔢 Versionamento Semântico (SemVer)  

O projeto segue o padrão:  


- **MAJOR** → mudanças incompatíveis com versões anteriores  
- **MINOR** → novas funcionalidades compatíveis  
- **PATCH** → correções de bugs e pequenos ajustes  

### Exemplo de versão:
```
2.0.0
```
